# Техническое руководство: Преобразователь частоты Lenze ESMD152X2SFA (1.5 кВт)

Однофазный преобразователь частоты **Lenze ESMD152X2SFA** с базовым модулем ввода-вывода (Basic I/O) предназначен для регулирования скорости вращения трехфазных асинхронных двигателей и бесколлекторных шпинделей мощностью до 1.5 кВт. Применяется в качестве силового привода шпинделя в составе фрезерного станка с ЧПУ **RA0306-02**.

## 4. Схема и назначение клемм управления (Basic I/O)

Логические входы работают по схеме: LOW = 0...+3 В (пассивное состояние), HIGH = +12...+30 В (активное состояние).

| Клемма | Назначение | Описание и характеристики цепей |
| :---: | :--- | :--- |
| **7** | Аналоговая земля (GND) | Общий провод для аналогового сигнала задания частоты вращения. |
| **8** | Аналоговый вход (0...10 В) | Принимает управляющий сигнал напряжения от ЧПУ для изменения оборотов шпинделя (входное сопротивление более 50 кОм). |
| **9** | Выход опорного питания (+10 В) | Выход встроенного стабилизатора для подключения внешнего ручного потенциометра (макс. нагрузка 10 мА). |
| **20** | Выход питания цифровых входов (+12 В) | Используется для запитки дискретных управляющих входов (макс. нагрузка 20 мА). |
| **28** | Вход разрешения хода "Старт/Стоп" | **HIGH (+12...30 В)** — запуск инвертора и вращения шпинделя.<br>**LOW (0...3 В)** — немедленный останов (выбегом или по рампе). |
| **E1** | Цифровой вход 1 (параметр `CE1`) | По умолчанию настроен на активацию **фиксированной скорости JOG1** (20 Гц). |
| **E2** | Цифровой вход 2 (параметр `CE2`) | По умолчанию настроен на **направление вращения** (LOW = по часовой стрелке, HIGH = против часовой стрелки). |
| **E3** | Цифровой вход 3 (параметр `CE3`) | По умолчанию настроен на активацию **торможения постоянным током (DCB)**. |
| **K12** | Релейный контакт (Выход реле) | Нормально разомкнутый сухой контакт. Настраивается параметром `C08`. По умолчанию реле замыкается при готовности прибора и **размыкается при возникновении ошибки (авария TRIP)**. Подключается к цепи аварийной блокировки станка E-Stop. |
| **K14** | Общий контакт реле |

## 5. Анализ совместимости со шпинделем станка RA0306-02

### Техническое противоречие характеристик:
*   **Характеристики шпинделя (QW1.5/220/24K):** Номинальная частота составляет **400 Гц**, что соответствует максимальным оборотам **24 000 об/мин** для 2-полюсного двигателя.
*   **Характеристики инвертора:** Согласно базовому руководству пользователя для ПО серии 20, максимальный предел для параметра максимальной частоты `C11` зафиксирован на значении **240 Гц**.

### Следствие и расчет реальных оборотов:
Если инвертор заблокирован на значении 240 Гц, реальная максимальная скорость шпинделя будет ограничена:
$$\text{Обороты}_{max} = \frac{60 \times f}{p} = \frac{60 \times 240 \text{ Гц}}{1 \text{ (пара полюсов)}} = 14\,400 \text{ об/мин}$$
Шпиндель потеряет около 40% от паспортной скорости вращения.

### Способ решения при пусконаладке:
1.  Перейдите к параметру **`C11`**.
2.  Попробуйте поднять его значение кнопками вверх до **400.0 Гц**.
3.  Если прошивка вашего экземпляра ESMD152X2SFA является расширенной (поддерживает работу до 500 Гц), параметр успешно сохранится в EPM-модуль, и шпиндель выдаст полные 24 000 об/мин. В противном случае работа будет физически ограничена частотой 240 Гц (14 400 об/мин).

## 6. Базовые параметры настройки шпинделя (1.5 кВт, 220 В)

Для корректной работы шпинделя станка введите следующие значения параметров:

*   **`C01` = 0:** Задание оборотов идет от внешнего аналогового сигнала платы ЧПУ 0...10 В (клемма 8).
*   **`C11` = 400.0 Гц** (или максимально доступное значение до 240.0 Гц): Максимальная скорость вращения шпинделя.
*   **`C14` = 2:** Линейная характеристика U/f с фиксированным подъемом напряжения на низких частотах.
*   **`C15` = 400.0 Гц** (или номинальная частота шпинделя по его шильдику): Базовая опорная частота двигателя для формирования правильной кривой напряжения.
*   **`C16` = 4.0...6.0%:** Форсирование пускового момента (Boost). Не завышайте параметр, чтобы избежать перегрева шпинделя на холостом ходу.
*   **`C18` = 2 (8 кГц) или 3 (10 кГц):** Частота ШИМ. На 10 кГц шпиндель работает тише, но инвертор сильнее нагревается.
*   **`c20` (Защита двигателя $I^2t$) = 71%:** Настройка защиты. Рассчитана на номинальный ток шпинделя в 5.0 А относительно номинального тока инвертора 7.0 А ($5.0 / 7.0 \times 100\% \approx 71\%$). Предотвращает перегорание обмоток.

## 7. Коды ошибок аварийного отключения (TRIP)

В случае нештатных режимов работы дисплей инвертора отображает коды ошибок. Сброс ошибки производится снятием сетевого питания на 3 минуты или подачей кратковременного сигнала LOW-HIGH на клемму запуска 28.

| Код ошибки | Вероятная причина | Способ проверки и устранения |
| :---: | :--- | :--- |
| **F1** | Отсутствует или неисправен съемный чип памяти EPM. | Отключите питание, плотно установите EPM-модуль в гнездо на лицевой панели. |
| **CFG** | Конфликт настройки входов `E1...E3`. | Проверьте параметры `CE1...CE3`. Одна и та же функция назначена на два входа одновременно. |
| **0C1** | Короткое замыкание в нагрузке или мгновенная перегрузка по току. | 1. Проверьте силовой кабель и обмотки шпинделя на замыкание фаз.<br>2. Увеличьте время разгона (параметр `C12`).<br>3. Уменьшите значение пускового подъема напряжения `C16`. |
| **0C2** | Замыкание одной из фаз двигателя на "землю" (корпус). | Произошел пробой изоляции обмотки шпинделя или жил кабеля на корпус станка. Проверьте цепи мегаомметром. |
| **0C6** | Тепловой перегрев двигателя по модели расчетного нагрева $I^2t$. | Шпиндель длительное время работал с перегрузкой по моменту. Дайте мотору остыть. Проверьте соответствие уставки в параметре `c20`. |
| **0H** | Перегрев радиатора инвертора. | Нарушена вентиляция шкафа ЧПУ или температура внутри превышает +55 °C. Очистите вентиляторы охлаждения инвертора. |
| **OU** | Перенапряжение на шине постоянного тока инвертора (более 400 В DC). | 1. Напряжение электросети превысило 264 В AC.<br>2. Слишком резкое торможение шпинделя с высокой скорости (увеличьте время торможения `C13`). |
| **LU** | Недостаточное напряжение питания инвертора. | Напряжение электросети просело ниже 180 В AC. Проверьте питающую линию станка под нагрузкой. |
| **Sd5** | Обрыв линии аналогового задания 4...20 мА. | Произошел обрыв провода управления скоростью от платы ЧПУ к клемме 8 (если выбран режим контроля тока `C34` = 4). |#
