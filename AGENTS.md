# AGENTS.md

Правила для работы с этим репозиторием (для агентов и участников).

## Общее

- Репозиторий **публичный**: ничего секретного (пароли, токены, ключи) сюда не коммитить.
- Лицензия проекта — **MIT** (`LICENSE`), покрывает только собственные материалы. Сторонняя документация остаётся под авторским правом владельцев.
- Структура: каждый станок — отдельная папка в `machines/<модель>/`.
- Файлы мануалов — md-выжимки (текстовые копии), PDF в репозиторий не добавлять.

## Авторские права (обязательно)

1. Вся сторонняя документация в `machines/*/manuals/` принадлежит своим правообладателям (Purelogic R&D, Lenze и др.) и размещена **только как офлайн-копия для справки**.
2. Каждый такой файл **обязан** иметь в шапке блок атрибуции: `© правообладатель`, название документа, ссылку на официальный источник и пометку «офлайн-копия для справки».
3. Не удалять и не править блок атрибуции. Не заявлять авторство на чужие документы.
4. При заимствовании фрагментов чужих документов в свои материалы — указывать источник.
5. Новый сторонний материал добавлять только с атрибуцией и ссылкой на источник; без необходимости проприетарные документы целиком не публиковать (лучше ссылка).
6. Наш авторский код и тексты (инструкции, конфиги) распространяются свободно.
