# mach3-to-linuxcnc

Переход с проприетарного Mach3 на LinuxCNC: инструкции, справочные материалы и конфиги по конкретным станкам с ЧПУ.

## Идея

Mach3 — проприетарное ПО для управления станками. Проект собирает в одном месте всё необходимое для перехода на свободный LinuxCNC: руководства по станкам и их компонентам (как офлайн-копии с атрибуцией), пошаговые инструкции по настройке и будущие готовые конфиги (`.ini` / `.hal`).

## Структура

```
docs/
└── linuxcnc-migration-guide.md   # общий гайд: Mach3 → LinuxCNC (любой станок)

machines/
├── ra0306/      # Purelogic RA0306-02 (портальный фрезер, драйвер PLC545)
└── aman4060/    # Aman 4060 (в работе)

offline/                        # установка на станок БЕЗ интернета
├── fetch-packages.py           # скачать .deb + зависимости (на любом ПК)
├── setup-machine.sh            # прогнать на станке: система «как после установки»
└── dotfiles/                   # клавиши, автозапуск LinuxCNC, ПКМ-меню
```

Каждая папка станка содержит:

- `README.md` — сводка «что имеем» и состав папки;
- `manuals/` — документация по станку и компонентам;
- `linuxcnc-<станок>-guide.md` — инструкция перехода на LinuxCNC;
- `configs/` — конфиги LinuxCNC (по мере готовности).

Быстрый старт: прочитай `docs/linuxcnc-migration-guide.md`, затем гайд своего
станка; для установки без интернета — `offline/README.md`.
