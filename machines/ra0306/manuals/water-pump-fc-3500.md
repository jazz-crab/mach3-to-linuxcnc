# Технический паспорт: Погружная водяная помпа FC-3500

Погружная водяная помпа FC-3500 предназначена для обеспечения циркуляции охлаждающей жидкости (воды) в замкнутых системах охлаждения шпинделей фрезерных станков с ЧПУ, лазерных трубок и другого промышленного оборудования.

---

## 1. Технические характеристики

| Параметр | Значение |
| :--- | :---: |
| **Модель изделия** | FC-3500 |
| **Рабочее напряжение сети** | 220 В переменного тока (AC) |
| **Потребляемая мощность** | 75 Вт |
| **Максимальная высота подъема воды** | 3.5 м |
| **Максимальная производительность** | 3500 л/ч |
| **Тип выходного соединения (резьба)** | G1/2" |

---

## 2. Габаритные и посадочные размеры

Корпус помпы оснащен мягкими резиновыми присосками для надежной фиксации на дне резервуара с охлаждающей жидкостью.

*   **Длина корпуса (максимальная по основанию):** 139 мм (длина верхней части корпуса — 95 мм)
*   **Полная длина прибора (с учетом выступающих частей):** 150 мм
*   **Высота корпуса (без штуцера):** 95 мм
*   **Полная высота прибора (с учетом выходного штуцера):** 110 мм
*   **Ширина корпуса:** 70 мм
*   **Расстояние между осями присосок по ширине:** 74 мм (общая ширина по краям присосок — 88 мм)
*   **Расстояние между осями присосок по длине:** двухступенчатое расположение опор с межосевыми расстояниями 60 мм и 68 мм.
*   **Положение выходного штуцера:** Смещение оси штуцера G1/2" составляет 54 мм от переднего края помпы и 85 мм от заднего края корпуса.
