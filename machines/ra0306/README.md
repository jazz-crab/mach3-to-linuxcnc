# RA0306-02 (Purelogic)

Портальный фрезерный станок с ЧПУ, переход с Mach3 на LinuxCNC.

## Что имеем

| Узел | Модель / параметр |
|------|-------------------|
| Станок | Purelogic RA0306-02, портальный фрезер |
| Оси | X 640 мм, Y 350 мм, Z 100 мм |
| Передача | ШВП Ø16, шаг 5 мм/об (все оси), ремень 1:1 |
| Моторы | PL57H76-D8, 1.8° → 200 полных шагов/об |
| Драйвер | PLC545 (LPT, адрес 0x378), до 4 осей |
| БП осей | S-350-48 + дампер PLZ005-G2 |
| Шпиндель | QW1.5/220/24K-D80/ER11 (до 24 000 об/мин) |
| Частотник | Lenze ESMD152X2SFA (1.5 кВт, 0…10 В) |
| Концевики | Датчики PLL01 (SN04-Nct), входы на плате |
| Помпа СОЖ | FC-3500 (75 Вт, 3500 л/ч) |
| Было ПО | Mach3 + профиль с purelogic.ru |

## Состав папки

- `linuxcnc-ra0306-guide.md` — пошаговая инструкция перехода на LinuxCNC (LPT, PLC545, StepConf).
- `manuals/` — документация по станку и компонентам (офлайн-копии с атрибуцией):
  - `ra0306-02.md` — руководство по эксплуатации станка (пины, схемы, ТО);
  - `lenze-esmd152x2sfa.md` — частотник шпинделя (клеммы, параметры, ошибки);
  - `damper-plz005-g2.md` — дампер (защита драйверов от обратной ЭДС);
  - `water-pump-fc-3500.md` — помпа охлаждения.
- `configs/` — конфиги LinuxCNC (по мере настройки).
